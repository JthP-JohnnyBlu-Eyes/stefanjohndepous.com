# stefanjohndepous.com

Personal website of Stefan John de Pous: poetry (Dutch and English), library, Jungian depth psychology, alchemy, the torus, coaching and The Torus Letter.

A single static page (`index.html`), no build step. Hosted with GitHub Pages; `CNAME` points it at stefanjohndepous.com.

## Editing content

All content lives in `index.html`:

- **Poems:** the `POEMS` list in the script (`en` and `nl`).
- **Books:** the `BOOKS` list. Set `AMAZON_TAG` to your Amazon Associates tag to earn from links.
- **Coaching offers and prices:** the `#coaching` section.
- **Bio:** the `#profile` section.
